# NEGM MEMORIES — ملفات الموقع

## الملفات
- `index.html`: الواجهة والتطبيق الأمامي.
- `assets/logo.svg`: شعار SVG فعلي للموقع.
- `manifest.webmanifest` و`sw.js`: أساس PWA والعمل الجزئي دون اتصال.
- `404.html`: مساعدة أولية لمسارات GitHub Pages.
- `firebase-rtdb-rules.json`: قواعد مقترحة كبداية، راجعها قبل النشر.
- `supabase-storage-policies.sql`: سياسات تخزين ملفات المستخدمين في bucket خاص.
- `SETUP-AR.md`: خطوات الإعداد بالعربية.

## مهم قبل الاستخدام الحقيقي
هذا مشروع واجهة متكامل وظيفيًا في جانب المتصفح، لكنه لا يصبح آمنًا للنشر العام بمجرد رفع الملفات. طبّق قواعد Firebase وSupabase المرفقة واختبرها بحسابين منفصلين. بعض ميزات الإنتاج مثل حذف الحساب الكامل، الإشعارات الفورية، معاينات Open Graph الديناميكية، الردود على التعليقات، وتحويل الصوت إلى نص تحتاج وظائف خلفية وخدمات إضافية؛ الواجهة لا تدّعي أنها مفعّلة.

## Firebase
إعدادات Firebase Web التي زود بها صاحب المشروع موجودة داخل `index.html`. فعّل Google ضمن Authentication، وأضف نطاق GitHub Pages والدومين الفعلي إلى Authorized domains.

## Supabase
رابط المشروع مضاف داخل `index.html`. أدخل المفتاح العام anon/publishable في الإعدادات داخل الموقع. لا تضع `service_role` في الواجهة. أنشئ bucket باسم `memories` واجعله Private، ثم طبّق السياسات المناسبة. الكود الحالي يبني رابط public object افتراضيًا؛ لذلك إذا كان bucket خاصًا، يجب استخدام signed URLs أو API وسيط قبل نشر ملفات خاصة. لا تنشر ملفات المستخدمين الخاصة كرابط عام.
